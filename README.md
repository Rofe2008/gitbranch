# 🏨 Perfect Place - Лоиҳаи Бронкунии Меҳмонхонаҳо

Ин лоиҳа як вебсайти муосир барои ҷустуҷӯ ва брон кардани меҳмонхонаҳо мебошад, ки бо истифода аз технологияҳои веб сохта шудааст. Лоиҳа аз ду саҳифаи асосӣ иборат аст: саҳифаи асосии сайт ва саҳифаи логин/ворд.

## 🚀 Линки Зиндаи Сайт (Live Demo)
Шумо метавонед натиҷаи зиндаи лоиҳаро дар ин ҷо бинед:
👉 [https://rofe2008.github.io/gitbranch/](https://rofe2008.github.io/gitbranch/)

---

## 🛠 Технологияҳои Истифодашуда (Tech Stack)

* **HTML5** — Барои сохтори асосии саҳифаҳо.
* **Tailwind CSS** — Барои стилҳо, рангубор ва мутобиқшавӣ (Responsive design).
* **Git & GitHub** — Барои назорати версияҳо ва нигоҳдории кодҳо дар шохаҳои (branches) алоҳида.

---

## 📂 Сохтори Лоиҳа (Project Structure)

```text
├── src/
│   ├── input.css       # Файли асосии CSS барои Tailwind
│   ├── output.css      # Файли генерацияшудаи Tailwind
│   └── [суратҳо]       # Логотип ва суратҳои меҳмонхонаҳо
├── index.html          # Саҳифаи асосии сайт (Home Page)
├── indexlogin.html     # Саҳифаи логин ва воридшавӣ (Login Page)
├── tailwind.config.js  # Танзимоти Tailwind CSS
├── package.json        # Файли танзимоти Node.js
└── README.md           # Маълумот дар бораи лоиҳа
